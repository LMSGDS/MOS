Cài MOS Dock tự động

Trình duyệt không kéo được cửa sổ Word / Excel / PowerPoint. Cài plugin MOS Dock một lần trên máy — Windows dùng Setup.exe, macOS dùng gói .pkg hoặc file .zip.

Tải cài đặt Windows (.exe) Tải cài đặt macOS (.pkg / .zip)

Windows

  1. Tải và chạy MOS-Dock-Setup-Windows.exe (không cần Admin).
  2. Cài xong MOS Dock tự mở, đăng ký protocol mosdock:, chạy cùng Windows.
  3. Vào lại MOS, chọn Word/Excel/PowerPoint, bấm mở trên máy.

macOS

  1. Tải MOS-Dock-Setup-macOS.pkg (hoặc file .zip). Nếu là zip: giải nén rồi nhấp đúp Cai MOS Dock.command.
  2. Cho phép MOS Dock trong Cài đặt hệ thống → Quyền riêng tư → Accessibility (để kéo cửa sổ Office).
  3. Nếu macOS chặn app chưa ký: chuột phải → Mở.
