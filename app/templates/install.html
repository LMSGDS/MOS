Cài MOS Dock / KulKul

Trình duyệt không kéo được cửa sổ Word / Excel / PowerPoint. Cài plugin một lần trên máy.

Tải cài đặt Windows (.exe) Tải cài đặt macOS (.zip)

Windows

  1. Tải và chạy MOS-Dock-Setup-Windows.exe (không cần Admin).
  2. Cài xong MOS Dock tự mở, đăng ký protocol mosdock:, chạy cùng Windows.
  3. Vào lại MOS, chọn Word/Excel/PowerPoint, bấm mở trên máy.

macOS

macOS hiện hộp thoại Not Opened / Move to Trash với file .pkg vì gói chưa được Apple ký (notarize). Không dùng .pkg — tải .zip bên trên.

  1. Tải MOS-Dock-Setup-macOS.zip, giải nén.
  2. Chuột phải file Cai MOS Dock.command → Mở → Mở (đừng nhấp đúp nếu Mac báo Move to Trash).
  3. Cho phép MOS Dock trong Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Accessibility.
  4. Vào lại MOS, chọn Word/Excel/PowerPoint.

Hoặc mở Terminal rồi dán lệnh này (không bị Gatekeeper chặn):

curl -fsSL https://mos.gds.edu.vn/cai-dat/macos.sh | bash

Nếu đã tải nhầm .pkg: Cài đặt hệ thống → Quyền riêng tư & Bảo mật → kéo xuống → Open Anyway. Gói .pkg chỉ dùng được sau khi trường có tài khoản Apple Developer để ký. Tải .pkg.
