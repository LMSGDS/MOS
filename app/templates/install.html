Cài MOS-KulKul

Đăng nhập và chọn Word / Excel / PowerPoint ngay trong MOS-KulKul trên máy. Trình duyệt không kéo được cửa sổ Office.

Tải bộ cài nhỏ Windows Tải bản đầy đủ (offline) Tải cài đặt macOS (.zip)

Windows

  1. Tải MOS-KulKul-Setup-Windows.exe (file nhỏ, chỉ chứa liên kết máy chủ). Không cần Admin.
  2. Chạy file, bấm Cài đặt — máy tải bản đầy đủ từ mos.gds.edu.vn rồi mở trình cài MOS-KulKul.
  3. Không có mạng: dùng bản đầy đủ offline (~50MB).
  4. Mở MOS-KulKul, chọn Word / Excel / PowerPoint, đăng nhập.
  5. Demo tất cả bài tập: mở Word, menu ⋮ → Demo tất cả bài tập. MOS-KulKul tự chạy Find / Go To / Save PDF / Inspect rồi chấm. Hoặc MOS-KulKul.exe --demo-all.

macOS

macOS chặn gói .pkg chưa ký Apple. Tải .zip.

  1. Tải MOS-KulKul-Setup-macOS.zip, giải nén.
  2. Chuột phải Cai MOS-KulKul.command → Mở → Mở.
  3. Cho phép MOS-KulKul trong Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Accessibility.
  4. Mở MOS-KulKul, chọn Word/Excel/PowerPoint rồi đăng nhập.

Hoặc mở Terminal rồi dán:

curl -fsSL https://mos.gds.edu.vn/cai-dat/macos.sh | bash

Gói .pkg chỉ dùng khi đã notarize. Tải .pkg.
