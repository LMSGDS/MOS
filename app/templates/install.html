Cài MOS Dock tự động

Trình duyệt không kéo được cửa sổ Word / Excel / PowerPoint. Cài plugin MOS Dock một lần trên máy — Windows dùng Setup.exe, macOS dùng gói .pkg.

Tải cài đặt Windows (.exe) Tải cài đặt macOS (.pkg)

Windows

  1. Chạy MOS-Dock-Setup-Windows.exe (không cần Admin).
  2. Cài xong MOS Dock tự mở, đăng ký protocol mosdock:, chạy cùng Windows.
  3. Vào lại MOS, chọn Word/Excel/PowerPoint, bấm mở trên máy.

macOS

  1. Mở MOS-Dock-Setup-macOS.pkg, cài vào Applications.
  2. Cho phép MOS Dock trong Cài đặt hệ thống → Quyền riêng tư → Accessibility (để kéo cửa sổ Office).
  3. Nếu macOS chặn app chưa ký: chuột phải → Mở.

Nếu nút tải báo chưa có file: lấy artifact CI MOS-Dock-Setup-Windows / MOS-Dock-Setup-macOS rồi copy vào data/installers/ trên server.
