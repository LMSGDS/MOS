Cài MOS-KulKul {{ app_version }}

Bản {{ app_version }} — đăng nhập và chọn Word / Excel / PowerPoint ngay trong MOS-KulKul trên máy. Thanh Navigation bung hết chiều ngang; kéo mép để đổi kích thước. Máy đang chạy bản cũ thì cài lại bằng lệnh bên dưới. Trình duyệt không kéo được cửa sổ Office.

Đừng bấm Tải file trên Chrome/Edge — trình duyệt luôn quét virus vì bộ cài nhà trường chưa mua chữ ký Authenticode (không phải mã độc). Cài bằng lệnh PowerShell bên dưới: máy tự tải từ mos.gds.edu.vn, không đi qua thanh tải của trình duyệt.

Windows — lệnh cài (không bị Chrome quét)

  1. Bấm Bắt đầu, gõ PowerShell, mở Windows PowerShell.
  2. Dán lệnh rồi Enter:
$ErrorActionPreference='Stop'; [Net.ServicePointManager]::SecurityProtocol=[Net.SecurityProtocolType]::Tls12; $d=Join-Path $env:TEMP 'MOS-KulKul'; New-Item -ItemType Directory -Force $d|Out-Null; $f=Join-Path $d 'MOS-KulKul-Setup.exe'; Write-Host 'Dang tai ban day du (~50MB), chi cai mot lan...'; Invoke-WebRequest 'https://mos.gds.edu.vn/cai-dat/windows-full' -OutFile $f -UseBasicParsing; Unblock-File $f; Start-Process $f
Tải cài đặt macOS (.zip)

Đã mở cửa sổ PowerShell thì dán nguyên dòng trên (đừng gõ thêm powershell -Command). Lệnh tải bản đầy đủ rồi mở một cửa sổ cài — không qua bộ cài nhỏ (tránh cài hai lần). Nếu Windows SmartScreen: Thông tin thêm → Chạy anyway. Sau khi cài: mở MOS-KulKul, đăng nhập, menu ⋮ → Demo tất cả bài tập.

Cách cũ: tải file (Chrome/Edge sẽ quét virus)

ZIP vẫn chứa .exe nên trình duyệt vẫn có thể quét. Chỉ dùng khi không mở được PowerShell.

ZIP Windows (bộ cài nhỏ) ZIP bản đầy đủ (offline)

Tải .exe trực tiếp: bộ cài nhỏ · bản đầy đủ. MOS-KulKul-Setup-Windows.exe. Cảnh báo «tệp không phổ biến» → Giữ lại, không Discard. Unblock-File sau khi giải nén.

macOS {{ app_version }}

Bộ cài Mac {{ app_version }} — kéo MOS-KulKul.app vào Applications. Gatekeeper chặn .pkg chưa notarize; ưu tiên .zip hoặc lệnh Terminal.

  1. Tải MOS-KulKul-Setup-macOS.zip, giải nén.
  2. Nếu thấy MOS-KulKul.app: kéo vào Applications, rồi chuột phải → Mở → Mở.
  3. Nếu chỉ thấy Cai MOS-KulKul.command: chuột phải → Mở → Mở.
  4. Cho phép MOS-KulKul trong Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Accessibility.
  5. Mở MOS-KulKul, chọn Word/Excel/PowerPoint rồi đăng nhập.
Tải MOS-KulKul-Setup-macOS.zip

Hoặc mở Terminal rồi dán:

curl -fsSL https://mos.gds.edu.vn/cai-dat/macos.sh | bash

Gói .pkg cùng phiên bản chỉ dùng khi đã notarize. Tải MOS-KulKul-Setup-macOS.pkg.
